**Beautiful colored comments and powerful TODO management for VS Code.**

A modern, clean, and highly useful extension that enhances code comments and TODO tracking — with great support for both English and Polish tags.

---

## ✨ Features

- **Beautiful colored comments** for different tags
- **Advanced TODO Tree View** in the sidebar with quick navigation
- **Support for Polish tags** (`DO ZROBIENIA`, `POPRAW`, `UWAGA`, `POMYŚL`)
- **Quick command** to add new TODOs (`Ctrl+Shift+P` → "Better Todos: Add TODO")
- **Click to jump** directly to any TODO in the code
- **Auto-updating** decorations and tree view
- Lightweight and fast

### Supported Tags

| Tag            | Color      | Meaning                  |
|----------------|------------|--------------------------|
| `TODO`         | Yellow     | General task             |
| `FIXME`        | Red        | Needs fixing             |
| `HACK`         | Orange     | Temporary solution       |
| `NOTE`         | Blue       | Important note           |
| `REVIEW`       | Purple     | Needs review             |
| `OPTIMIZE`     | Pink       | Can be improved          |
| `DO ZROBIENIA` | Yellow     | Polish: To do            |
| `POPRAW`       | Red        | Polish: Fix              |
| `UWAGA`        | Orange     | Polish: Attention        |
| `POMYŚL`       | Green      | Polish: Think about      |

## Installation

1. Open **Extensions** in VS Code (`Ctrl+Shift+X`)
2. Search for **`Better Todos & Comments`**
3. Click **Install**

Or install from `.vsix` file.

---

## Usage

### Add new TODO quickly
Press `Ctrl+Shift+P` and type **"Better Todos: Add TODO"**

### Open TODO Explorer
Click the **Better Todos** icon in the Activity Bar (sidebar)

### Supported file types
Automatically works with: TypeScript, JavaScript, Python, Go, Rust, C++, C#, PHP, HTML, CSS, and more.
